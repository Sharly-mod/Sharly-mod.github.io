# Documents E5 — à déposer ici

Ce dossier est volontairement vide dans le dépôt : les documents personnels ne
doivent pas être versionnés. Le site vérifie leur présence au build et affiche
« À déposer » tant qu'un fichier manque.

## Fichiers attendus

| Fichier | Contenu |
| --- | --- |
| `tableau-synthese-e5.pdf` | Tableau de synthèse des réalisations professionnelles |
| `attestation-stage.pdf` | Attestation de stage DydyITServices / TIS-INGÉ (juin-juillet 2026) |
| `convention-stage.pdf` | Convention de stage signée (optionnel) |
| `rapport-stage.pdf` | Rapport de stage TIS-INGÉ / GestioParc (optionnel) |
| `cv-sharly-farag.pdf` | CV à jour pour l'alternance / poursuite d'études |

## Avant l'oral

1. Déposer les fichiers avec exactement ces noms.
2. Relancer `npm run build` (ou `npm run dev`) pour que les badges passent à
   « Disponible ».
3. Vérifier chaque bouton de téléchargement sur la page `/e5/`.
4. Vérifier que les PDF ne contiennent pas de données personnelles inutiles
   (adresse, téléphone, etc.) si le site est public.

> Les fichiers déposés ici sont publiés tels quels sur GitHub Pages.
